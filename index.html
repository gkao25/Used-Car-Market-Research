What have you done so far?

Up to this point we have cleaned our dataset to include the important factors that we believe, and our exploratory analysis showed, to be the most impacting to a car's resell value. That being manufacturing year, number of kilometers driven, and number of imperfections. We added transmission type (automatic vs manual) and a dropdown filter for models for user preference while shopping. We have also chosen to use a gradient to differentiate all the different models because the dataset initially had over 200 different models and we did not want to miss out on potential models that are outliers due to their trim level. Lastly, we incorporated a dual range slider so the user can change the min/max values of the variables.

What will be the most challenging of your project to design and why?

The most challenging part of our project to design was the visualization itself. It wasn't exactly clear how we wanted to visualize it or how to incorporate an interaction. We eventually settled on the beehive plot along with sliders to change min/max values along with a check box as our interaction. However, another problem arose when designing the color-palette of the graph. We knew we were going to highlight the points that fall within a range but we didn't know how to show that there were multiple models. Since there were over 200 different models we couldn't hard color code them or assign a set color-palette. Instead we chose to use a gradient to show the different models.
